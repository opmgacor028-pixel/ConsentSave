# ConsentSave — Build dari HP

Project ini sudah dilengkapi GitHub Actions untuk membuat APK secara online.

## Cara build tanpa laptop
1. Buat akun GitHub dan buat repository baru.
2. Upload seluruh isi project ini ke repository.
3. Buka tab **Actions**.
4. Pilih **Build ConsentSave APK**.
5. Jalankan **Run workflow**.
6. Setelah selesai, buka hasil workflow dan bagian **Artifacts**.
7. Download `ConsentSave-debug-apk`, ekstrak, lalu pasang `app-debug.apk` di HP.

## Catatan
Aplikasi hanya menyimpan media yang diberikan melalui mekanisme berbagi resmi/izin pemilik.
Tidak ada bypass View Once, root, Accessibility Service, screenshot interception, atau pembacaan
database WhatsApp.
